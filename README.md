A **basic and user-friendly login page** built using **HTML & CSS only**.  
Perfect for beginners, portfolio projects, and small applications that need a clean login interface.

---

## 🌟 Overview

This project includes a minimal login form where users can enter their:

- ✉️ Email or Username  
- 🔑 Password  

It is lightweight, easy to customize, and can be used as a template for larger systems.

---

## 🛠️ Technologies Used

- **HTML5** for page structure  
- **CSS3** for styling  

No JavaScript or backend yet.

---

## ✨ Features

- 🎨 Clean and simple user interface  
- 📦 Easy to integrate into any project  
- 🔐 Password input field with hidden characters  
- 🧱 Beginner-friendly code structure  
- 📱 Can be made responsive with media queries  

---
